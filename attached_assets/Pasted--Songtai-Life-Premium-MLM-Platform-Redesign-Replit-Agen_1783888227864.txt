## HOW TO USE THIS

Do **not** paste the whole thing into Replit Agent at once — that's how you get a shallow, half-finished pass across every screen instead of a deep one.

Feed these **one prompt block at a time**, in order. Wait for each phase to fully complete (and review its output) before starting the next. Every block below is self-contained and copy-pasteable as-is.

Every single prompt starts with the same mandatory preamble — don't skip it, even if it feels redundant:

```
Before making any changes:
1. Read ARCHITECTURE.md in full.
2. State which skill(s) from the 66-skill guide (jeffallan/claude-skills,
   github.com/jeffallan/claude-skills) you are activating for this task,
   and why.
3. Confirm the existing design token system (Green #016934, Vermillion
   #E7380D, light/dark mode) before proposing any new colors — extend it,
   don't replace it.
Only then proceed with the task below.
```

## APPENDIX — Distilled Best-Practice Reference
### (use as design inspiration, not a scraping task for the agent)

Modern MLM/direct-selling platforms that do this well (Atomy, QNET,
Amway's newer regional sites) tend to share these patterns — reference
these principles when redesigning, rather than asking the agent to
browse the live sites:

- **Dashboard first, catalog second** — distributors log in to see
  their numbers, not a shopping page.
- **Progressive disclosure on the comp plan** — rank/commission logic
  is explained in layers (simple summary → detailed breakdown), not
  dumped as one dense table.
- **Trust signals near money actions** — verified payout badges,
  clear withdrawal timelines, visible support contact near
  checkout/wallet screens.
- **SaaS-grade dashboards** (Stripe/Linear-style): generous whitespace,
  one primary stat per card, muted secondary data, restrained color
  use reserved for status/alerts only.
