It's a bilingual (English/French) direct-selling wellness site for Songtai Life Cameroon. ## 3. Pages to build / update

### 3.1 About / Our Story page (`/about` or `/notre-histoire`, whatever the existing route convention is)
- Hero/intro pulling `page_sections.home.company_intro.story_en/fr`
- Stats strip: years, members, products, countries, awards (from same section)
- Leadership section: render `homepage_sections.page_our_story_team.content.members[]` as a card — photo (fallback avatar if `photo_url` empty), name, role, bio, with a "read more" toggle for the bio since it's long
- Certification strip: render `page_our_story_certs.content.certs[]` as icon + label + sublabel badges
- Keep this in sync with whatever the homepage's `company_intro` section already renders — don't create a second source of truth; if the homepage has a short teaser, link "Read our full story" through to this page

### 3.2 Products page (`/products` or `/produits`)
- Fetch `products` joined to `product_categories`, filtered by `is_active = true` (so the 7 seeded products **will not show yet** until pricing is finalized — that's intentional, don't force them visible)
- Group/filter by category using `name`/`name_fr`
- Product card: image (placeholder graphic if `images` is empty), localized name, localized description (truncate with "read more"), price formatted as XAF only if `price_xaf > 0`, PV badge only if `pv_points > 0`
- Product detail page/modal at `/products/[slug]`

### 3.3 FAQ page (`/faq`)
- Fetch `faq_categories` ordered by `display_order`, and `faqs` where `is_published = true` ordered by `display_order`, grouped under their category
- Accordion UI per category tab or section — question in the active locale, answer collapses/expands
- Add a simple client-side search/filter across question text (both locales) if the existing site has a search pattern elsewhere; otherwise keep it simple

### 3.4 Blog page (`/blog`)
- List `blog_posts` where `status = 'published'` (the 3 seeded posts are `draft` — they intentionally will not show until reviewed and published from admin)
- Blog index: title (localized via `title`/`title_fr`), excerpt, category badge, author, published date
- Blog detail page at `/blog/[slug]` rendering `body` (render as paragraphs/markdown — check how `body` is currently formatted elsewhere in the codebase before assuming plain text vs markdown)
- If there's an existing admin panel for `blog_posts`, verify the 3 draft posts appear there for Zayne to add images and publish — don't build a duplicate admin UI if one exists

## 4. Non-negotiables
- Every string shown to a visitor must have both an English and French rendering, switching correctly with the locale toggle — no hardcoded fallback language
- Do not flip `is_active` on products or `status` on blog_posts to make things "look done" — leave that gating to Zayne, since pricing/images aren't final
- Reuse existing design tokens/components (buttons, section headers, card styles) already in the codebase — don't introduce a new visual language for these four pages
- Add loading and empty states for every list (products, faqs, blog) since `products` and `blog_posts` are currently empty-of-visible-rows by design (all inactive/draft)
